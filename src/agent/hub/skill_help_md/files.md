**Files Skill**

The Files skill helps you work with files and folders on your computer.

**What it helps with**
- Searching for files by name, type, or location
- Finding documents like payslips, invoices, reports, and PDFs
- Copying, moving, renaming, zipping, and unzipping files
- Scanning folders and checking disk usage
- Delivering files back in the current chat for download

**Try asking things like**
- How many payslips are there on my computer?
- Zip my project folder and send it here
- Find all PDF invoices in Downloads

**Common mistakes**
- Say the folder name if you want me to search in one place only.
- Say whether you want to search, move, rename, zip, or send the file.
- If you want the file back in chat, say "send it here" or "download here".

**How to operate it safely**
- Say `file`, `folder`, or the path explicitly when the request could be confused with another skill.
- For cleanup or organization, prefer phrases like `clean up that folder` or `organize my Downloads folder`.
- If you mean email cleanup instead, say `mailbox cleanup` explicitly.
