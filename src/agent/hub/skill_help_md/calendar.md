**Calendar Skill**

The Calendar skill helps you manage events, reminders, and your schedule.

**What it helps with**
- Viewing your agenda for today or this week
- Creating, updating, and deleting events
- Finding free time slots
- Setting reminders and recurring events
- Checking conflicts in your calendar

**Try asking things like**
- What's on my calendar tomorrow?
- Create a meeting with Rahul at 4 PM on Friday
- Find a free 30-minute slot this afternoon
- Setup my calendar preferences
- Show my calendar preferences
- Edit my calendar preferences
- Review my calendar

**Common mistakes**
- Include a date and time if you want me to create an event.
- Say how long the event should be if you want me to find a slot.
- Mention attendees if the event involves other people.

**How to operate it safely**
- Use Calendar for direct event work like create, move, delete, or review events.
- If you want optimized planning or focus blocks, ask for Scheduler explicitly.
- Say the date window clearly for month or week summaries.

**Preferences**
- Calendar now supports durable markdown-backed defaults for working hours, meeting duration, and reminder timing.
- Those defaults are used for slot-finding, quick-add meeting requests, and reminder setup only when you do not provide more specific instructions.
