**Google Drive Skill**

The Drive skill helps you find and manage files in Google Drive.

**What it helps with**
- Finding files and folders quickly
- Uploading, downloading, moving, and renaming files
- Sharing files with other people
- Creating folders and organizing Drive content
- Checking storage usage and duplicates

**Try asking things like**
- Find the latest invoice in Drive
- Upload this report to my Finance folder
- Share the Q4 deck with alice@example.com

**Common mistakes**
- Say the folder name if you want me to upload or move something.
- Say who to share with if the task involves sharing.
- If there are similar files, mention the file name clearly.
