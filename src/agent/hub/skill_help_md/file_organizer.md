**File Organizer Skill**

The File Organizer skill helps you clean up folders safely by showing a plan before making changes.

**What it helps with**
- Scanning messy folders and proposing an organization plan
- Sorting files by type, date, or naming pattern
- Archiving older files
- Previewing changes before anything is moved
- Setting and running archival policies

**Try asking things like**
- Organize my Downloads folder by file type
- Show me a cleanup plan for my Desktop
- Archive files older than 6 months in this folder

**Common mistakes**
- Use this skill for folder cleanup, not for simple file search.
- Say which folder you want organized.
- If you want a rule, mention how files should be grouped, like by type or by date.
