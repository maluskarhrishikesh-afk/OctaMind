**Browser Skill**

The Browser skill helps you search the web, open pages, and summarize what they contain.

**What it helps with**
- Searching the web for information
- Opening web pages and extracting content
- Summarizing articles and websites
- Listing links and important page details
- Downloading files from URLs

**Try asking things like**
- Search for the latest OpenAI news
- Summarize this webpage for me
- Open this URL and list the important links

**Common mistakes**
- Share the exact URL if you already have one.
- Say what you want from the page: summary, links, facts, or a download.
- If you want fresh information, say "latest" or "current".
